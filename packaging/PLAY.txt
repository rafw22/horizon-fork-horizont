Horizont: High-Performance Multi-Core Rust Minecraft Engine
=============================================================

Horizont is an independent, performance-first fork of the Rust Minecraft
engine, maintained by rafw22. It features parallel Rayon entity ticking,
1-second instant boot times, a native DLL modloader, and a built-in World
Downloader (WDL) with 3D chunk overlays.

Horizont is an unofficial fan project, not affiliated with, endorsed by or
connected to Mojang Studios or Microsoft. Minecraft is a trademark of Mojang
and Microsoft. This folder contains none of Minecraft's code, textures or
sounds: Horizont prepares them from your own copy of Minecraft Java Edition.

Playing Horizont
  To prepare this folder by hand you need Minecraft Java Edition 26.3, played
  once from the official launcher, and a Java 25 runtime. Then, in this folder:
    ./horizon-prepare --prepare --server-jar PATH/TO/server.jar
    ./horizon-prepare sounds               (optional, for sound)
  (Windows: horizon-prepare.exe.) The 26.3 server jar is the downloads.server.url
  in your launcher's versions/26.3/26.3.json. Add --minecraft-dir PATH to both if
  your launcher keeps the game elsewhere. Then run
  ./horizon-client (horizon-client.exe on Windows).

Fast Boot & Power Features:
  ./horizon-client --last-world          Jump directly into latest singleplayer world in ~1 second
  ./horizon-client --server host:port    Jump directly into multiplayer server
  Drop compiled .dll mods into mods/     Native dynamic mod execution with zero recompile delay

Controls: mouse look, WASD move, Space jump, Left Shift sneak, Left Ctrl
sprint, left click break, right click place/use, 1-9 or scroll for the hotbar,
E inventory, Q drop, F1 hide the HUD, F3 debug, Esc pause.

Running a server
  horizon-server, in this folder, hosts a server with this engine:
    ./horizon-server --dir my-server init     the EULA, world, seed, port, who may join
    ./horizon-server --dir my-server start    in the background; also stop, restart
    ./horizon-server --dir my-server status   TPS, MSPT, players, RAM and CPU
